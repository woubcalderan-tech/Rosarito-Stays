# Project roadmap

1. **Foundation** — Local tooling, shared design and layout primitives, route skeletons, and a data-driven suite template.
2. **Public pages** — Approve logo, photography, suite inventory and content. Implement the reference page sections and galleries, then test desktop and mobile designs. Confirm routes for Property Details, Local Guide and related reference navigation.
3. **Reservations** — Define inventory and booking rules. Integrate Supabase, availability, payments, confirmations and administration.
4. **Launch** — Finalize English and Spanish content, legal pages and production SEO. Connect source control hosting and deploy to Hostinger when authorized.
