# Archived Las Olas Grand photography

All 48 JPGs in `sample-photos/` are supplied photographs from the Las Olas Grand condominium project. They depict Las Olas Grand. The local Phase 3 application uses the separate fictional collection. The selected derivatives below describe the historical v0.2.0-preview release. The source directory is ignored by Git and sits outside Vite's public directory.

For exact responsive filenames and art direction, see the [AI photography replacement inventory](PHOTO-REPLACEMENT-INVENTORY.md).

Copies use WebP quality 83, a standard sRGB color space and composition-specific crops. Widths run from 360 to 1440 px without upscaling. The homepage identifies the source of the temporary photography beside the imagery. Its other routes hold no sample images.

The archived release used the samples in local and review builds. Public review permission applied to the selected samples. The local Phase 3 conversion supersedes those derivatives and their on-screen credit. The original JPGs remain in the ignored archive.
