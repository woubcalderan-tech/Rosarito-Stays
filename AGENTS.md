# Rosarito Stays project guidance

- Use `design-references/` as the visual authority and preserve those files. Read numbered page sections in ascending order.
- Keep property content in configuration and data. Use the shared suite template at `/accommodations/:slug`.
- Confirm property facts and photos before integrating them. Treat mockup claims as design content until verified.
- Keep the current phase local. External integrations and publication require later scope.
- Run type check, lint, format check, and build before handing off. Check the affected routes in desktop and mobile layouts.
